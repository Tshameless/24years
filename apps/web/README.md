# 24Years Web

孕期记录与家庭协作 Web 应用。Vue 3 + TypeScript 前端，Node.js 原生 HTTP + SQLite 服务端；完整产品愿景见根目录 `docs/`。当前实现账号、家庭模式、父母身份、配对、共享计划和账本、角色权限与跨端同步。多人模式目前支持母亲、父亲两位成员。

## 运行与检查

环境：Node.js **24.9+**、pnpm 11。服务端使用 Node 内置 TypeScript 执行和 `node:sqlite`（运行时会输出实验性 API 提示），不依赖额外数据库服务。

```powershell
pnpm install --frozen-lockfile
pnpm dev:api
```

另一个终端在相同目录执行：

```powershell
pnpm dev --host 127.0.0.1 --port 5173 --strictPort
```

访问 <http://127.0.0.1:5173>。Vite 将 `/api` 转发到 `127.0.0.1:8787`。数据库默认在 `data/family.sqlite`，目录已忽略提交；重启仍保留账号和记录。本机记录按浏览器来源隔离，请固定使用同一地址和端口。

```powershell
pnpm type-check
pnpm format:check
pnpm lint
pnpm lint:style
pnpm test
pnpm test:api
pnpm exec playwright install chromium
pnpm test:e2e
pnpm build
```

E2E 自动启动前端 `4173` 与独立内存数据库 API `8788`，不会写入开发数据库；覆盖桌面和 Pixel 7 视口、两个独立浏览器的配对和同步。截图及失败跟踪保存在 `test-results/`。

## 使用流程与权限

1. 建档表单首先选择「单人」或「多人」，首次不预选。单人适用于未婚生育、单亲妈妈等独立记录场景，无需绑定另一位家长；多人必须选择自己是母亲还是父亲，父亲填写的是母亲的怀孕时期。
2. 本机模式无需账号即可保存该选择、档案、计划和账目。在「我的家庭」注册/登录后，点击「上传本机档案并开启同步」沿用已保存的类型与身份。本机原始记录始终保留。也可以直接在已登录的账号内填写档案，保存时创建同步家庭。
3. 管理员可在档案表单将单人家庭改为多人并选择父母身份，保存后生成 6 位邀请码或复制配对链接。邀请码 24 小时有效、只能用一次；重新生成/撤销后旧码失效。
4. 另一位家长用自己的账号，选择母亲/父亲身份并输入邀请码加入。已有同一身份时拒绝加入且不消耗邀请码。每个账号只能属于一个家庭，每个家庭最多两人；已有家庭的账号不能自动迁移或合并。加入前有共享范围确认。
5. 在其他设备登录同一账号即可恢复该成员身份与家庭数据。邀请另一位成员时应使用不同账号。

| 权限                                   | 管理员                   | 共同编辑 | 仅查看 |
| -------------------------------------- | ------------------------ | -------- | ------ |
| 查看、导出家庭共享数据                 | 是                       | 是       | 是     |
| 计划与账目新增/编辑/删除、打卡         | 是                       | 是       | 否     |
| 家庭档案、静默关怀、模式设置           | 是                       | 否       | 否     |
| 邀请、撤销邀请、调整伴侣权限、解除配对 | 是                       | 否       | 否     |
| 主动退出家庭                           | 保留家庭，可解除伴侣配对 | 是       | 是     |

权限由服务端检查，前端禁用按钮仅作提示。「仅查看」仍可查看完整账本，不是隐藏财务的亲属角色；亲属/孩子账号不在本次双人功能范围内。解除配对后服务端立即拒绝对方访问，在线页面下次同步清除共享视图；已下载的数据不能远程撤回。历史记录留在原家庭。需解除配对后才能改回单人模式。

家庭身份与权限独立：母亲或父亲都可作为创建者成为管理员，另一位默认共同编辑。旧本机档案按原有单人行为读取；旧多人数据库增加可空身份列，保留原有记录和权限，不猜测父母身份，由成员自行补选。后端 `couple` 值继续保留以兼容已有数据库，对用户统一显示「多人」。

## 同步与冲突约定

- 每 2 秒拉取当前家庭，重新聚焦和网络恢复时也会同步；响应带家庭修订号，旧响应不会覆盖新状态。
- 写入发送单条记录及编辑前快照，在 SQLite 事务中比较。不同记录可分别保存；同一记录被修改/删除时返回 `409`，保留当前输入，展示最新列表，用户重新打开编辑。不会静默覆盖或自动强制重试冲突。
- 记录写入携带操作编号。响应丢失时，在当前页面重试同一草稿使用相同编号，服务端返回已完成结果，避免重复记账。
- 网络中断时可查看已加载内容、继续填写当前表单；保存失败会明确提示，不显示成功。未保存输入仅在当前页面，导航/刷新会丢失；不实现离线写队列或断网冷启动缓存。
- 已同步数据以服务端为准，不写回本机 v1 存档；退出账号后恢复本机档案。主题只影响本机，不随伴侣同步。
- 登录使用 scrypt 加盐密码哈希、30 天随机会话、HttpOnly/SameSite Cookie；数据库仅存会话和邀请码哈希。写接口检查来源、自定义请求头、参数、成员权限；登录和配对带尝试次数限制。

## 部署与数据保存

生产构建后可用同一服务提供静态页面和 API：

```powershell
pnpm build
$env:APP_ORIGIN = 'https://family.example.com'
$env:COOKIE_SECURE = 'true'
$env:FAMILY_DB = 'D:/24years-data/family.sqlite'
pnpm start
```

这是部署配置示例，没有替你部署公网服务。通过 HTTPS 反向代理同一站点到 `127.0.0.1:8787`，两台设备访问同一 HTTPS 地址；`APP_ORIGIN` 必须与外部地址完全一致。本机测试不需要设置这些环境变量。浏览器随机 ID 使用安全上下文 API，跨设备使用 HTTPS。

| 环境变量           | 默认值                        | 用途                                     |
| ------------------ | ----------------------------- | ---------------------------------------- |
| `API_PORT`         | `8787`                        | API / 静态站点监听端口                   |
| `API_HOST`         | `127.0.0.1`                   | 监听地址，通常置于反向代理后             |
| `FAMILY_DB`        | `apps/web/data/family.sqlite` | 数据库绝对路径；测试可用 `:memory:`      |
| `APP_ORIGIN`       | 请求的 HTTP Host              | 允许写请求的页面来源；HTTPS 部署必须配置 |
| `COOKIE_SECURE`    | `false`                       | HTTPS 部署设为 `true`                    |
| `API_PROXY_TARGET` | `http://127.0.0.1:8787`       | Vite 开发代理目标                        |

单实例服务，SQLite WAL 事务保证写入一致性。部署需提供持久化磁盘，并在停止服务后备份数据库（含尚未合并的 `-wal` / `-shm` 文件，或使用 SQLite 一致性备份机制）。业务数据未做静态加密；数据库目录仅授权服务进程访问，导出文件含完整记录。当前不提供密码找回、邮箱验证、账号删除或多实例协调。不要把开发服务器当公网生产环境。

## 代码结构与数据约定

```text
server/
  database.ts             SQLite 表结构与事务
  service.ts              账号、家庭、权限、配对、记录变更
  http.ts                 路由、Cookie、来源验证、限流、静态文件
  index.ts                启动与关闭
  service.test.ts         权限/并发/持久化/HTTP 验证
src/
  domain/                 家庭类型、协作契约、验证、日历和金额运算
  composables/useFamily.ts       本机存档与家庭操作
  composables/useCollaboration.ts 会话、网络请求、自动同步、错误状态
  components/family/      档案表单、独立账号面板、配对与成员管理
  components/tasks/       计划容器、表单、列表
  components/ledger/      账本容器、表单、列表
  views/                  路由页面组合
e2e/                      本机及双端用户流程
```

组件使用 Composition API 与 `<script setup lang="ts">`，共享状态通过带类型的 provide/inject 提供。编辑表单接收记录快照，通过 `saved` / `cancel` 事件通知容器；列表只发出编辑/删除/打卡事件。网络状态集中在 composable，页面不直接请求 API。

- 本机键 `24years.family.v1` / JSON `version: 1` 不变；档案新增可选 `familyMode` / `parentRole`，缺少字段的旧档案继续可读。同步时家庭类型和成员身份分别落在家庭表与成员表；修改档案时在同一事务内更新。损坏存档原样保留、锁定写入，旧标签页覆盖检测继续生效。JSON 导出可用，导入尚未实现。
- 金额以整数分保存。净支出 = 支出 − 已报销 − 已到账津贴，允许负值，津贴不重复计入支出或报销。
- 计划支持一次性或每日重复；打卡按日期保存。时间只用于排序，不发送系统通知。
- 建档输入 0–42 已满孕周、0–6 天，按表单日期与项目 40 周约定推算 `dueDate`，保留旧存档兼容性；仅作日历参考。
- 静默关怀隐藏首页孕周、倒计时和计划，保留历史；同步家庭中由管理员设置并共享。
- 格式统一为两空格、100 字符行宽、LF；Vue 多属性逐行排列，函数、条件分支、样式规则间留空行。
