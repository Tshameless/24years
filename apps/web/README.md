# 24Years Web

孕期记录与家庭协作 Web 应用。Vue 3 + TypeScript 前端，Node.js 原生 HTTP + SQLite 服务端；完整产品愿景见根目录 `docs/`。当前交付孕期 Web MVP：账号、家庭模式、父母身份、配对、共享计划和账本、产检安排、体征记录、宫缩计时、就医卡、角色权限与跨端同步。多人模式目前支持母亲、父亲两位成员。

## 孕期记录

- 胎教陪伴：内置两首古诗原文和一篇原创陪伴短文；可选本机音频手动播放/暂停。音频只在当前页使用，不上传、不随备份保存，刷新需重新选择；不提供商业音乐库、配乐朗诵、录音采集或胎教效果承诺。陪伴内容和手动填写的时长可保存、编辑和删除。
- 心情日记：五种心情与文字备注，支持编辑、删除。启用同步后家庭成员均可见，并非私密日记；不含心理测评或诊断。
- 待产清单：自定义物品、分类（最多 30 字）、数量（1–9999 整数）、角色负责人、备注和备齐状态，可编辑、删除；新增可编辑整理模板。已保存的待准备物品编辑为备齐时，可填写采购金额，与完成状态原子入账到「待产准备」。留空或 0 不入账，记录日期也是支出日期。已有账目不重复创建，后续金额在账本修改，删除物品保留账目。三类记录均沿用本机/共享存储、权限、冲突保护和 JSON 备份恢复。
- 网站标签页使用品牌叶芽 SVG favicon，随生产构建发布。

- 建立家庭档案后，从「孕期记录」进入产检、体征、计时和就医卡；手机底部导航与桌面侧栏均可访问。
- 产检支持新增、编辑和删除。编辑待产检记录时勾选完成，可同时填写费用和已报销金额；完成状态和新账目原子保存，重试不会重复入账。留空或费用为 0 时不新增账目。后续费用修改在账本进行，删除产检不删除历史账目。
- 体征支持体重（kg）、血压（mmHg）和血糖（mmol/L），可编辑、删除并附测量备注。可选填测量时当地时间（HH:mm）及测量场景（最多 80 字），历史与趋势数据表同步展示；旧记录和旧草稿兼容，未知时间保持空缺。支持按指标、日期筛选的趋势图及原始数据表，血压分两条曲线。按日历日期定位、同日测量不猜测先后，纵轴自动缩放；不做诊断和临床范围判断，不混合不同指标单位。
- 「胎动记录」支持大按钮加一、误点减一、直接修改次数，以及观察开始日期/时间、实际观察时长和备注。次数允许 0；保存后可编辑、删除、家庭同步及 JSON 备份恢复，未提交计数支持当前标签页草稿恢复与冲突保护。可选自动计时（1–1440 分钟），支持提前结束、刷新恢复、返回页面按截止时间补算；结束后显示站内提示，并填入时长供核对，用户确认后手动保存。提前结束不足一分钟按一分钟填入。计时草稿只属于当前标签页，不跨设备同步。
- 胎动计时可在当前页面主动启用系统通知、提示音与设备支持的振动；静默关怀下仅保留站内结果。通知权限拒绝、通知发送失败或音频不可用时仍保留站内提示。刷新、切换草稿或离开页面后需重新启用声音与通知；后台休眠、锁屏、关闭网页不能保证准时提醒，可同时使用手机闹钟。计时依赖系统时钟，不过滤连续动作、不换算全天次数、不输出异常判断；文档中的两套计数算法须统一并审核后另行接入。
- 产检新增三种可编辑就诊准备模板，只填名称和备注，不自动选择日期或检查项目；不是临床产检时间轴，实际安排请向医院确认。
- 宫缩以开始/结束时间计算持续时长，展示相邻开始的间隔；同一家庭只能有一次活动计时。刷新可恢复，关闭页面不会自动结束，也不提供后台提醒。请及时结束；系统时钟调整可能影响时长。安静关怀期间不能开始新计时，已有计时可结束或丢弃。
- 就医卡记录医院、紧急联系人、电话、过敏史与用药备注，可在支持的设备上点击拨号。此信息与其他记录一样对当前家庭全部成员可见；仅查看成员不能修改。
- 新数据使用可选的 `pregnancyRecords` 字段，兼容旧 v1 存档；本机上传、共享同步、JSON 导入导出与服务端数据库备份均包含该字段。导入也会恢复活动计时，请核对开始时间。

此版本覆盖孕期核心记录闭环；长期育儿阶段、附件与报告识别、关闭网页后的推送、离线写入和公网部署仍未实现。

## 离线应用壳

生产版本在 HTTPS（或本机 localhost / 127.0.0.1）下首次联网打开后，安装 Service Worker 并缓存应用入口和静态代码。缓存完成后，断网刷新和打开其他应用路由仍能显示页面；开发服务器不注册 Service Worker。浏览器清理缓存后需再次联网打开。

本机模式继续使用当前浏览器存档。云端家庭数据、API 和版本检查不进入应用缓存：离线刷新后不能恢复云端记录，云端写入失败不会显示成功，也没有离线写队列。页面会显示连接状态及能力边界。新版 worker 等旧版页面全部关闭后接管，避免自动刷新打断表单。

## 账本月度统计与 CSV 导出

- 家庭账本可按月份与分类组合筛选，提供「本月」与「重置筛选」。顶部累计汇总始终覆盖全部账目；筛选汇总、明细和导出范围一致，金额按整数分计算，净支出允许为负值。
- 月份按账目发生日期归属；已报销金额仍随原支出归月，不是实际报销到账月的现金流统计。津贴按其记录日期归月，不重复计入支出。未提交草稿不参与统计，切换筛选不清除当前表单。
- 「导出当前筛选 CSV」在确认后下载当前可见的已保存记录，按日期倒序、同日按编号排序。包含记录编号、日期、类型、分类、名称以及支出/报销/津贴/净支出，金额单位人民币元；不额外附加汇总行，避免二次求和重复计算。空筛选禁用导出，只读成员仍可导出已有查看权限的账目。
- CSV 使用 UTF-8 BOM、中文表头、两位小数及文本字段转义；公式开头等危险文本加单引号保护，不修改原账目。文件包含家庭财务信息，请妥善保管。CSV 用于表格分析，不能导入恢复家庭；完整备份恢复仍使用 JSON。不含图表、预算、支付人或跨月报销流水功能。

## 每周计划

- 重复方式支持一次性、每日、每周指定星期。每周至少选择一天，周一至周日可多选；从开始日期起，仅匹配星期的日期进入今日计划。全部计划可查看其他日期的记录，但不能在非计划日打卡。
- 完成状态按日期保存；修改重复方式保留历史打卡，切回每日或一次性时移除星期规则。周规则支持本机保存、共享同步、草稿刷新恢复和 JSON 备份；旧计划及旧草稿继续可读。
- 支持负责人（母亲、父亲、单人本人或不指定）和可选结束日期，结束日包含当天。负责人仅表示分工，不改变权限，所有可编辑成员仍可代为打卡；不支持双方独立完成或代打卡确认。不包含隔周或 Cron 规则。
- 新增四种常用计划模板，填入后可修改并显式保存；替换已有输入需确认。负责人和结束日期参与草稿、同步及 JSON 备份，旧记录无字段时维持原逻辑。
- 全站站内提醒按设备当地时间每 15 秒检查今天到时未完成、未指派或由本人负责的计划。静默关怀、只读或会话过期时隐藏。可主动授权开启本次页面会话的浏览器通知，通知不展示任务内容，当前会话同项同日同时间去重；刷新后需重新开启。关闭页面、后台休眠或断网不保证提醒，不是服务端推送或医疗报警。浏览器不支持或拒绝权限时仍可查看站内提醒，切换账号/权限/关怀状态时关闭通知。
- 新增 weekly 重复类型及 weekdays 字段，仍使用 v1 容器。前端和 API 必须配套更新；包含每周计划的新存档不能由旧版代码读取，回滚前应保留备份，不能将新存档强行覆盖为旧格式。

## 运行与检查

环境：Node.js **24.9+**、pnpm 11。服务端使用 Node 内置 TypeScript 执行和 `node:sqlite`（运行时会输出实验性 API 提示），不依赖额外数据库服务。

```powershell
pnpm install --frozen-lockfile
pnpm dev:api
```

另一个终端在相同目录执行：

```powershell
pnpm dev --host 127.0.0.1 --port 5173 --strictPort
```

访问 <http://127.0.0.1:5173>。Vite 将 `/api` 转发到 `127.0.0.1:8787`。数据库默认在 `data/family.sqlite`，目录已忽略提交；重启仍保留账号和记录。本机记录按浏览器来源隔离，请固定使用同一地址和端口。

```powershell
pnpm type-check
pnpm format:check
pnpm lint
pnpm lint:style
pnpm test
pnpm test:api
pnpm exec playwright install chromium
pnpm test:e2e
pnpm build
```

E2E 自动启动前端 `4173` 与独立内存数据库 API `8788`，不会写入开发数据库；覆盖桌面和 Pixel 7 视口、两个独立浏览器的配对和同步。截图及失败跟踪保存在 `test-results/`。

`pnpm test:e2e:pwa` 先构建生产版本，再通过 `8788` 静态服务验证桌面与手机的离线刷新、深链接、云端离线提示及缓存边界；CI 会自动执行此验证。

## 使用流程与权限

首次使用先选择本机或账号使用，再建立家庭档案。保存后可直接进入第一项计划、下一次产检，或回首页查看指引。首页指引按真实已保存的数据显示进度，支持收起、刷新后保留收起选择并重新展开；开启静默关怀时不展示。

孕期工具按「日常陪伴 / 产检与健康 / 待产与应急」分组，保留八个具体入口及查询参数直达地址，默认进入产检安排。家庭页优先展示档案，把账号、协作与备份集中在可收起的次要管理区（默认展开，折叠保留表单草稿）。

1. 建档表单首先选择「单人」或「多人」，首次不预选。单人适用于未婚生育、单亲妈妈等独立记录场景，无需绑定另一位家长；多人必须选择自己是母亲还是父亲，父亲填写的是母亲的怀孕时期。
2. 本机模式无需账号即可保存该选择、档案、计划和账目。在「我的家庭」注册/登录后，点击「上传本机档案并开启同步」沿用已保存的类型与身份。本机原始记录始终保留。也可以直接在已登录的账号内填写档案，保存时创建同步家庭。
3. 管理员可在档案表单将单人家庭改为多人并选择父母身份，保存后生成 6 位邀请码或复制配对链接。邀请码 24 小时有效、只能用一次；重新生成/撤销后旧码失效。
4. 另一位家长用自己的账号，选择母亲/父亲身份并输入邀请码加入。已有同一身份时拒绝加入且不消耗邀请码。每个账号只能属于一个家庭，每个家庭最多两人；已有家庭的账号不能自动迁移或合并。加入前有共享范围确认。
5. 在其他设备登录同一账号即可恢复该成员身份与家庭数据。邀请另一位成员时应使用不同账号。
6. 注册后保存一次性恢复密钥；旧账号可在「账号安全与注销」验证当前密码生成。忘记密码时使用密钥重置，所有旧登录失效；重新登录后生成新密钥。服务端只保存密钥摘要，不提供查看历史明文密钥。
7. 「你的记录，由你掌握」支持 JSON 文件预览与确认恢复。本机恢复保留原始存档（包括损坏内容）；同步家庭仅管理员可恢复，保留成员、身份和权限。系统保留最近一次导入前副本供下载，替换前也建议自行导出。
8. 注销需当前密码、账号名称及确认。唯一成员注销删除整个家庭与导入前副本；管理员有另一位成员时转交管理权并保留共享记录，普通成员注销仅退出并删除自身账号。本机记录、下载文件和运维备份不自动清除。

| 权限                                   | 管理员                   | 共同编辑 | 仅查看 |
| -------------------------------------- | ------------------------ | -------- | ------ |
| 查看、导出家庭共享数据                 | 是                       | 是       | 是     |
| 计划与账目新增/编辑/删除、打卡         | 是                       | 是       | 否     |
| 家庭档案、静默关怀、模式设置           | 是                       | 否       | 否     |
| 邀请、撤销邀请、调整伴侣权限、解除配对 | 是                       | 否       | 否     |
| 主动退出家庭                           | 保留家庭，可解除伴侣配对 | 是       | 是     |

权限由服务端检查，前端禁用按钮仅作提示。「仅查看」仍可查看完整账本，不是隐藏财务的亲属角色；亲属/孩子账号不在本次双人功能范围内。解除配对后服务端立即拒绝对方访问，在线页面下次同步清除共享视图；已下载的数据不能远程撤回。历史记录留在原家庭。需解除配对后才能改回单人模式。

家庭身份与权限独立：母亲或父亲都可作为创建者成为管理员，另一位默认共同编辑。旧本机档案按原有单人行为读取；旧多人数据库增加可空身份列，保留原有记录和权限，不猜测父母身份，由成员自行补选。后端 `couple` 值继续保留以兼容已有数据库，对用户统一显示「多人」。

## 同步与冲突约定

- 前台每 2 秒条件拉取当前家庭，后台暂停；重新聚焦、返回前台和网络恢复时也会同步。ETag 基于账号、成员权限、家庭修订及有效邀请元数据生成；未变化时返回 304，不解析家庭 JSON。失败后指数退避，最长 60 秒；旧响应不会覆盖新状态。
- 写入发送单条记录及编辑前快照，在 SQLite 事务中比较。不同记录可分别保存；同一记录被修改/删除时返回 `409`，保留当前输入，展示最新列表，用户重新打开编辑。不会静默覆盖或自动强制重试冲突。
- 记录写入携带操作编号。响应丢失时，在当前页面重试同一草稿使用相同编号，服务端返回已完成结果，避免重复记账。
- 网络中断时可查看已加载内容、继续填写当前表单；保存失败会明确提示，不显示成功。生产版支持应用壳缓存，但不缓存云端数据，也不实现离线写队列。
- 日常计划与账本支持标签页草稿：输入暂存在 `sessionStorage`，刷新或站内返回可恢复，离页/刷新时提示未保存。新增与不同记录的编辑草稿分别保存；编辑草稿需重新打开对应记录，原记录已变化时禁止直接覆盖。草稿不会自动提交、不会同步、不进入 JSON 备份，关闭标签页后不保证保留；账号和家庭档案等表单尚未接入。
- 孕期产检、体征、胎动、陪伴、心情、待产和就医卡也支持标签页草稿，每类保留一份当前编辑内容及原记录快照，刷新自动恢复编辑状态。切换编辑记录会确认是否放弃现有草稿；恢复后原记录变化/删除或新增已保存时禁止直接覆盖。数量留空不推断为 1，旧物品缺少字段仍兼容。
- 草稿按账号、家庭、权限及记录隔离，退出/切换身份或降为只读时清除；仅确认保存成功或主动清除后删除当前草稿。浏览器禁止存储时会提示暂存失败，仍保留当前输入和离页提醒。离页提示受浏览器限制，尤其移动端强制关闭不保证弹出。
- 已同步数据以服务端为准，不写回本机 v1 存档；退出账号后恢复本机档案。主题只影响本机，不随伴侣同步。
- 登录使用 scrypt 加盐密码哈希、30 天随机会话、HttpOnly/SameSite Cookie；数据库仅存会话和邀请码哈希。写接口检查来源、自定义请求头、参数、成员权限；登录和配对带尝试次数限制。
- 导入以预览时家庭修订号检查并发，响应丢失时同一预览可安全重试。JSON 文件上限 800 KB，只支持替换恢复，不自动合并；旧版本 v1 存档兼容。恢复密钥操作及密码恢复也有限流。

## 部署与数据保存

生产构建后可用同一服务提供静态页面和 API：

```powershell
pnpm build
$env:APP_ORIGIN = 'https://family.example.com'
$env:COOKIE_SECURE = 'true'
$env:FAMILY_DB = 'D:/24years-data/family.sqlite'
pnpm start
```

这是部署配置示例，没有替你部署公网服务。通过 HTTPS 反向代理同一站点到 `127.0.0.1:8787`，两台设备访问同一 HTTPS 地址；`APP_ORIGIN` 必须与外部地址完全一致。本机测试不需要设置这些环境变量。浏览器随机 ID 使用安全上下文 API，跨设备使用 HTTPS。

| 环境变量           | 默认值                        | 用途                                     |
| ------------------ | ----------------------------- | ---------------------------------------- |
| `API_PORT`         | `8787`                        | API / 静态站点监听端口                   |
| `API_HOST`         | `127.0.0.1`                   | 监听地址，通常置于反向代理后             |

单实例服务，SQLite WAL 事务保证写入一致性。部署需提供持久化磁盘；`pnpm db:backup <源库> <新备份文件>` 可创建一致性快照，`pnpm db:verify <文件>` 校验，`pnpm db:restore <备份> <新数据库文件>` 生成恢复库并撤销旧会话和邀请。详见 [部署、定时备份与恢复演练](deploy/README.md)。业务数据未做静态加密；数据库目录仅授权服务进程访问，导出文件含完整记录。当前不提供邮件找回、邮箱验证或多实例协调。不要把开发服务器当公网生产环境。

```text
server/
  database.ts             SQLite 表结构与事务

deploy/                   Linux 服务、HTTPS 与备份定时器模板
src/
  domain/                 家庭类型、协作契约、验证、日历和金额运算

  composables/useCollaboration.ts 会话、网络请求、自动同步、错误状态
  components/family/      档案表单、独立账号面板、配对与成员管理

  components/ledger/      账本容器、表单、列表
  views/                  路由页面组合
e2e/                      本机及双端用户流程
```

组件使用 Composition API 与 `<script setup lang="ts">`，共享状态通过带类型的 provide/inject 提供。编辑表单接收记录快照，通过 `saved` / `cancel` 事件通知容器；列表只发出编辑/删除/打卡事件。网络状态集中在 composable，页面不直接请求 API。

- 本机键 `24years.family.v1` / JSON `version: 1` 不变；档案新增可选 `familyMode` / `parentRole`，缺少字段的旧档案继续可读。同步时家庭类型和成员身份分别落在家庭表与成员表；修改档案时在同一事务内更新。损坏存档原样保留、锁定普通写入，可通过已校验的备份恢复；旧标签页覆盖检测继续生效。本机导入前副本在 `24years.family.v1.before-import`，服务端副本在 `import_backups`。
- 金额以整数分保存。净支出 = 支出 − 已报销 − 已到账津贴，允许负值，津贴不重复计入支出或报销。
- 计划支持一次性、每日或每周指定星期重复、可选负责人和结束日期；打卡按日期保存。提醒仅覆盖打开页面时的站内检查和主动开启的页面会话通知。
- 建档输入 0–42 已满孕周、0–6 天，按表单日期与项目 40 周约定推算 `dueDate`，保留旧存档兼容性；仅作日历参考。
- 静默关怀隐藏首页孕周、倒计时和计划，保留历史；同步家庭中由管理员设置并共享。
- 格式统一为两空格、100 字符行宽、LF；Vue 多属性逐行排列，函数、条件分支、样式规则间留空行。
