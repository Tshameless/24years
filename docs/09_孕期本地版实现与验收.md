# 孕期本地版：实现范围与验收

更新日期：2026-10-20。本文记录当前代码实际能力；08 为目标规划，尚未完成的条目不能视作已交付。

## 当前可用流程

首次启动 → 建立孕期档案（医生确认的预产期）→ 今日首页 → 添加产检 → 完成产检并记录实际现金支付 → 查看账本与体征 → 导出备份。

- 无需注册、无需联网；一个本地孕期档案，妊娠 ID 独立于家庭生命周期。当前没有多档案切换。
- 产检支持新增、编辑、完成、取消完成及删除。完成产检可在同一数据库事务中生成一笔费用；再次完成会更新同一关联费用，不重复累加。删除产检保留已确认账单。
- 记录体重、血压、血糖及自定义时间段的胎动次数；只校验输入格式，不输出医学阈值结论。
- 账本按分保存金额；现金净流出 = 实际现金支付 − 后续报销到账 − 津贴到账。医保直接结算部分不再次扣减；不把该指标称为完整养育成本。
- 自建每日提醒与今日打卡。WorkManager 每 15 分钟检查一次，只补发目标时间后 60 分钟内的提醒；产检前一天 09:00 起检查。应用内明确提示这是非精确通知，后台限制可能使提醒延迟或漏发。
- 宫缩开始时先落库，再启动前台服务。持续时间使用 elapsedRealtime，不按 UI 刷新次数累加；通知提供停止按钮。设备重启后标为中断，恢复备份不续接旧设备时钟。未实现 5-1-1 医学判断或达标警报。
- 离线医疗卡记录医院、联系人、过敏及用药备注；拨号操作打开系统拨号界面确认。未内置未经审核的急救操作 SOP。
- 静默关怀隐藏首页孕周并暂停日常和产检通知，停止正在进行的计时（保留为中断记录），保留历史资料。恢复需确认。
- JSON 完整导出与恢复；恢复前校验版本、记录 ID、所属妊娠和关键字段，确认后以事务替换。文件不加密，界面明确告知；文件上限 10 MB。
- 本机清除操作需确认，取消通知与计时，并删除孕期记录。

## 数据与工程

- Room 数据库名 `24years.db`，schema 版本 2；1→2 手写迁移保留原家庭表，不采用破坏性清库。
- `pregnancies` 保存本次妊娠档案；`pregnancy_records` 按妊娠外键归属记录，带类型和版本化备份编解码。当前统一记录表适合本地起步；后续统计和同步增长时应迁移为更细的类型表。
- 业务记录通过 Repository 和 ViewModel 访问，Compose 订阅数据变化。当前无远程账号、云端同步、资源下载和 APK 自更新。
- 现有粉色主题与 OLED 主题继续使用，按钮前景调整为深色以提高可读性。

测试覆盖：孕周与闰年、金额精度与非法输入、负现金净流出、体征输入、全类型备份往返、重复 ID / 跨档案拒绝、计时恢复中断、重开数据库持久化、关联费用幂等、事务回滚与旧库升级。CI 配置位于 `.github/workflows/android.yml`，远程执行结果需在实际推送后查看。

## 仍需实机验收

1. Android 8 与 Android 14/15：首次建档、切换五个主页面、返回键、字体放大和深色模式。
2. 飞行模式记录并强制结束应用，重启后数据仍在；重新安装会清除本地数据，需提前备份。
3. 产检完成两次不重复入账；编辑 / 删除关联账单行为符合提示。
4. 宫缩计时熄屏 10 分钟、通知停止、进程回收和设备重启；验证时长与中断标记。
5. 通知权限拒绝 / 授权、厂商省电、静默关怀开启后不再发送日常通知；检查已有通知被清除。
6. 导出 → 清除 → 恢复；导入损坏文件、错误版本及超大文件应保留原数据。
7. 检查无拨号应用时的提示，及真实电话设备的拨号确认页面。

尚无真机或模拟器验收结论；不得把构建和单元测试通过等同于可公开发布。正式发布还需签名、安装 / 更新测试、医疗内容审核和实际分发准备。
